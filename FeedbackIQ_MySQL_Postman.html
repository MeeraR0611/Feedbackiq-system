① MySQL Database Setup SQL

🔧 How to switch from SQLite → MySQL

1
Install MySQL driver: pip install pymysql
2
Open MySQL Workbench and run the SQL below to create the database and user
3
In app.py, set USE_MYSQL = True and fill in your MYSQL_PASSWORD
4
Run python app.py — Flask auto-creates all tables via db.create_all()
📄 mysql_setup.sql — run this in MySQL Workbench 
-- ─────────────────────────────────────────────────────────────
-- FeedbackIQ MySQL Setup Script
-- Run in MySQL Workbench or MySQL CLI before starting the app
-- ─────────────────────────────────────────────────────────────

-- 1. Create the database
CREATE DATABASE IF NOT EXISTS feedbackiq
  CHARACTER SET utf8mb4
  COLLATE utf8mb4_unicode_ci;

USE feedbackiq;

-- 2. Create a dedicated user (change the password!)
CREATE USER IF NOT EXISTS 'feedbackuser'@'localhost'
  IDENTIFIED BY 'yourpassword';

GRANT ALL PRIVILEGES ON feedbackiq.* TO 'feedbackuser'@'localhost';
FLUSH PRIVILEGES;

-- 3. Tables (Flask/SQLAlchemy creates these automatically,
--    but here they are explicitly for reference)

CREATE TABLE IF NOT EXISTS user (
  id        INT          NOT NULL AUTO_INCREMENT,
  name      VARCHAR(100) NOT NULL,
  email     VARCHAR(120) NOT NULL UNIQUE,
  password  VARCHAR(200) NOT NULL,
  role      VARCHAR(20)  NOT NULL DEFAULT 'user',
  PRIMARY KEY (id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

CREATE TABLE IF NOT EXISTS feedback (
  id        INT          NOT NULL AUTO_INCREMENT,
  user_id   INT          DEFAULT NULL,
  message   TEXT         NOT NULL,
  sentiment VARCHAR(20)  NOT NULL,
  score     FLOAT        NOT NULL,
  timestamp DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (id),
  FOREIGN KEY (user_id) REFERENCES user(id) ON DELETE SET NULL
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- 4. Insert default admin user (password: admin123)
INSERT IGNORE INTO user (name, email, password, role) VALUES (
  'Admin',
  'admin@feedback.com',
  'scrypt:32768:8:1$...',  -- Flask will hash this on first run
  'admin'
);

-- 5. Verify tables created
SHOW TABLES;
DESCRIBE user;
DESCRIBE feedback;

③ Postman API Testing Results 9 Endpoints

POST http://localhost:5000/api/register 201 Created
Request Body (JSON)
{
  "name": "Test User",
  "email": "test@example.com",
  "password": "Test@123"
}
Response
{
  "message": "Registered successfully",
  "role": "user"
}
Result: User created in DB. Role auto-assigned as admin if email is admin@feedback.com, otherwise user. Duplicate email returns 409 Conflict.
POST http://localhost:5000/api/login 200 OK
Request Body (JSON)
{
  "email": "test@example.com",
  "password": "Test@123"
}
Response
{
  "message": "Login successful",
  "name": "Test User",
  "role": "user"
}
Result: Session cookie set. Wrong credentials return 401 Unauthorized with "error": "Invalid credentials".

Result: VADER compound score 0.8442 ≥ 0.05 → classified as Positive. Entry saved to DB with user_id from session.
